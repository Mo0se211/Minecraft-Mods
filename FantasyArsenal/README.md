# Fantasy Arsenal (NeoForge 1.21.1)

Built automatically by GitHub Actions: open the repository's **Actions** tab, pick the latest
"Build Fantasy Arsenal" run, and download **FantasyArsenal-jar** from the Artifacts section.

- `src/main/java` - the mod's code (items, creative tab, client setup)
- `resources.zip` - all textures, models, loot tables, structures and abilities
